Your design system

Every screen in this workspace is drawn from one small file of tokens. This page reads that file live — the values below are not a picture of the system, they are the system.

Colour

Six colours, one of them hot

Five quiet values carry the paper and the ink. The sixth marks the one thing on a screen you are meant to act on — a primary button, a step you are on, a pin. If two things on a screen wear it, neither one reads.

Try it

Change the hot ink

Pick one. Everything below — and the swatches above, and this page's own buttons — moves at once, because they all read the same token.

To keep it, write these three lines into skills/starter-ui/starter-tokens.css. The second is the same ink darkened until it passes contrast as text; the third is its quietest wash.

Or have your agent do it
Type

Two faces, seven sizes

Display type is monospaced — this is a workspace made of plain files, and the type says so. Body copy is the system sans, which every machine already has, so a screen looks the same the moment it opens with nothing to download.

Space

One rhythm, eight steps

Every gap in this workspace is one of these. Reaching for a number that is not on the ramp is the first sign a screen is drifting.

Parts

What is already built

Twelve parts, all classed .s-*, all drinking from the tokens. Brief your agent to use these before it invents anything new — that is what keeps twenty screens looking like one product.
