In the product

A destination, not a project.

  • A “Council” item in the navbar, at /council — always there.
  • Each plenary is an Event — date, agenda, reminders.
  • Verified sign-in gates the live vote — one resident, one voice.

“Space” is already taken in Go Vocal (an admin feature in development) — so this is the “Council,” not a space.

Clear-eyed

What's actually hard.

  • Real-time at scale is a build. Only Online Workshop is truly live today; the rest refresh.
  • No councillor role exists. The bench-side view is net-new.
  • Each council is wired by hand — agenda, record, calendar.

The first test

One council, one live session.

  1. Pick a council already on Go Vocal with a public agenda.
  2. Ship it: past recaps, one live session, what's upcoming.
  3. Put a tablet on the bench for one real plenary — and watch what changes.

In one line

Today the city speaks before and after. This lets it speak during.

That's the whole bet.
