Homepage-banner switcher — 3 layouts × signed-out / signed-in

The admin Homepage banner widget (Pages & menu → Homepage builder) renders the banner in one of three layouts, for a non-registered (signed-out) or registered (signed-in) visitor. Flip the live banner through every state — this switcher lives with the component; a page just drops in one configured state (the homepage uses full-width + signed-out).

Layouts: the homepage banner has three (live testids full-width-banner-layout / two-row-layout / fixed-ratio-layout). .layout-tworow shows the photo as its own top row (needs a .gv-hero__media child) with the content in a white band below — tenant-primary title, secondary subtitle, a filled primary CTA. .layout-fixed keeps the overlaid full-width look at a shorter fixed aspect ratio.

Signed-out vs signed-in: the non-registered banner shows the avatar cluster and a sign-up / custom CTA; the registered banner drops the avatars and uses its own CTA. A page drops in whichever single state it's configured for — the homepage uses full-width + signed-out.

Overlay: .gv-hero::before tints the banner with --gv-tenant-primary (multiply, 0.62) so it re-skins per city and keeps white text legible.

Photo: set style="--gv-hero-image:url(…)". With no image a tenant-neutral gradient shows — the prototype never looks broken without assets.

Avatars: .gv-avatars is the social-proof stack; give each .av a background-image for real faces, and set the .count pill.
