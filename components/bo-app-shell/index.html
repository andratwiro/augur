Project Editor chrome

The project-specific header that sits inside .gv-bo-main — only present in the Project Editor, not on other back-office pages (Dashboard, Users, etc.). Combines a project top-bar (title · status · actions) with the project tab row. The sidebar navigation is a separate bo-sidebar component.

Reuse: mount inside .gv-bo-main alongside bo-sidebar (which sits in the outer .gv-bo-shell grid). The topbar uses .gv-bo to remap --gv-tenant-* to GoVocal's fixed back-office palette, so primitives (.gv-btn.admin-dark, .gv-iconbtn, etc.) render in BO colours automatically.
