Sticky note

Pastel Perspectives idea card with author, emoji, title, excerpt and up/down react counts; comes in resting, raised, and four pastel variants.

Resting (pastel variants)

Raised (.is-raised — the floating detail card)

Pastel variants: .lavender, .mint, .pink, .grey each set the --gv-sticky-bg custom property; add a variant class to recolour the note.

States: add .is-raised for the floating, elevated detail card; the resting card is the masonry-pile default.

Anatomy: __author / __authorname / __emoji header, then __title + __excerpt, then the __react row of __reactbtn up/down buttons.
