Idea feed

The ideation feed layout — a result count above a two-column grid pairing the idea list with a 310px filter sidebar of sort, status and topic controls. The List/Map segmented toggle is optional (map-enabled phases only) and off by default, matching the real product.

Feed layout (list + filter sidebar)

Grid: .gv-feed is the two-column shell — .gv-feed__col holds the list, .gv-feedfilter is the fixed 310px sidebar. Cards sit in a flat .gv-idealist container.

Toggle (optional): the default feed shows only the .gv-feed__count total — the real product hides the view switcher unless the phase has map view enabled. Add data-map-enabled to .feed-head to reveal the .gv-viewseg toggle (two .gv-viewseg__tab buttons switching List / Map).

Status badge: each card foot carries a right-aligned .gv-ideacard__status — an uppercase, semantic-coloured outline pill (.is-implemented / .is-considered / .is-rejected, default = accepted/success green) sitting opposite the reaction controls.

Filters: each group is a .gv-feedfilter__label heading over a .gv-feedfilter__group of full-width .gv-feedfilter__btn rows, some carrying a trailing .gv-feedfilter__count badge; .is-active renders the row as a full-width tenant-coloured filled bar. SORT BY uses the .gv-feedfilter__group--sort variant: each row hugs the left with a leading .gv-feedfilter__icon (rocket / chat / trend / dice …) instead of a trailing count.

Mobile: below 860px the sidebar collapses behind a full-width .gv-filters-btn (sliders icon) shown above the list; tapping it toggles .is-open on .gv-feedfilter to reveal the panel inline.
