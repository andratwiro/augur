Layouts: the admin "Homepage banner" widget offers three — full-width-banner (base .gv-hero.signed-out), .layout-tworow (image row + white text band: tenant-primary title, filled CTA), and .layout-fixed (a shorter fixed-ratio overlaid strip). Two-row needs a .gv-hero__media child for its image row.

Banner: .gv-hero.signed-out = a fixed 450px full-bleed strip; the fallback canvas #EDEFF0 (--gv-bo-canvas) shows when no --gv-hero-image is set — matching the live fallback.

Overlay: the base .gv-hero::before tints with --gv-tenant-primary (the live overlay is St-Louis-blue @ .6 — i.e. the tenant primary), so the dark wash and the white text re-theme automatically.

Layout: content column padding 50px 30px, max-width 1012. Add .centered for the St-Louis / Copenhagen centered layout, or drop it for the default upper-left alignment.

CTA: a single .gv-btn.primary-inverse (white fill, rgba(0,0,0,.87) label, 14px, 13/22 padding baked into the variant) — a brand-neutral high-contrast button that reads on any tenant overlay.
