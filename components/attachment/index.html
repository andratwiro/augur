File attachment — download row

The Content-Builder "file attachment" widget — a downloadable-file row on a custom / info page (terms / about / archive). Source-grounded on St Louis (stlouis.govocal.com/pages/memos, capture fo-stlouis-infopage): a 24px paperclip glyph + the file-name link + a (NNN KB) size span, framed in a 1px #C8D0D7 outlined row (--gv-attachment-border), 3px radius. Cross-tenant structure; re-skins per ?theme=. Stack rows in a .gv-attachments list. Reference page: pages/custom-page/.
