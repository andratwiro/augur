Footer logo band (.gv-footer__logos): an optional white, centered strip rendered as a sibling above <footer> (measured padding 50px 20px 20px, logos height:100px). Add .row to lay multiple marks side-by-side (tenant + government); use .gv-footer__logos-cap for smaller partner logos. The tenant logo is a data-gv-logo slot so it re-themes per ?theme=.

Brand-tinted nav (.gv-nav.tinted): the only delta from the base nav is that labels take var(--gv-tenant-primary) instead of near-black — Lux's config. Active / hover / dropdown states are unchanged.

Dual auth CTAs (.gv-auth-dual): both a filled .gv-btn.primary log-in and an inverse .gv-btn.primary-inverse register, with the inverse label re-tinted to the brand colour. Both button variants already exist — this group only composes them. The signed-out language switcher sits alongside.

Powered-by is optional: keep .gv-footer__powered for tenants that show "Généré par Go Vocal" (Lux does), omit it where suppressed.
