Back-office menu & notification flyout

One canonical dropdown surface — .gv-bo-menu — shared by the Input-manager Exports menu and the bell Notification flyout (the product uses the same <Dropdown> for both). White card, 3px radius, 12px soft menu shadow. The .is-flyout variant fixes the width to 260px for the notification panel. The bell trigger carries the red .gv-badge.is-count.

Reuse: wrap any menu items in .gv-bo-menu for a dropdown panel; each row is a .gv-bo-menu__item (icon + label, 9 15 padding). Add .is-flyout to pin the panel to 260px and host .gv-bo-notifflyout__item rows (24px __icon + body text + __time); mark the latest unread with .is-unread. The .gv-badge.is-count is the standalone red count chip (radius 2px, not uppercase). All three render under the .gv-bo body scope so --gv-bo-primary resolves.
