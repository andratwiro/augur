How it's built. .gv-carousel is a wrapper around the canonical .gv-rail: the rail keeps all scroll/snap/fade mechanics; the carousel adds the header (a .gv-title.h2 + .gv-carousel__scroll prev/next chevrons), the role="region" / aria-roledescription="carousel" wrapper, and the .gv-carousel__skip "Press escape to skip carousel" button (sr-only until focused). Cards reuse .gv-pcard.light unchanged.

The prev button starts .disabled (left end). The page-local script below pages the rail and toggles the disabled state + the rail's fade classes — no .gv-* is redefined.
