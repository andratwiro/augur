Voting method body

The per-method panel that renders inside .gv-phasebody for a voting phase. Two parts: a collapsible .gv-voteoptions accordion of vote options, and the .gv-tally "Final tally" results panel followed by ranked .gv-voteresult cards. Source-grounded on wietsedemo …/approval-voting… (capture fo-approval-voting): accordion title (.e2e-accordion h3, 21/700/#474747), the Final-tally card (.hzyaEs, white/20px/soft-shadow), the headline count (.ZrGRl, 34/700/#333), the result card (.e2e-card, white/3px/17px/soft-shadow), the rank badge (.dcvdmw, bg #044D6C), the percentage line (.hgLDJh, 14/700/tenant-primary) and the fill track (.bsnfRS tinted 25% + 1px border / .kpdUEH solid).

Reuse: drop the markup into a project page's .gv-phasebody. The accordion rows are wired by a tiny page-local script (toggle aria-expanded on .gv-voteoption__head and .is-open on the matching .gv-voteoption__panel) — no JS lives in the canonical CSS. Reuses .gv-statuspill-style status conventions, the .gv-btn.text "Read more" button, and .gv-react__comment for the comment count. Set the option/result counts and bar widths inline; everything brand-coloured comes from --gv-tenant-primary, so it re-themes via ?theme=.
