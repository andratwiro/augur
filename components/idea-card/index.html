Idea card

The shared idea/proposal card — thumbnail, author meta, excerpt and a footer of circular like/dislike reaction controls with a comment count, used across project feeds.

Ideation card (reaction controls)

No-photo variant (icon thumb)

Reactions: .gv-react wraps two circular .gv-react__btn (like / dislike) each followed by a .gv-react__count; .gv-react__comment sits to the right with the comment icon and tally.

Thumb: .gv-ideacard__thumb holds an <img> or, with no photo, a data-gv-icon placeholder so the card never looks broken.

Author block: .gv-ideacard__head pairs an .gv-ideacard__avatar with .gv-ideacard__meta (__author • __time) and the .gv-ideacard__excerpt.
