Issue canvas

Dotted-grid Perspectives canvas that floats pastel sticky-note ideas in a masonry pile, with a floating "Add an idea" button.

Pile state (masonry of sticky notes)

Detail state (.is-detail — one raised note)

Canvas: .gv-issuecanvas draws the dotted grid and floats sticky notes; the __view wraps the content and __pile lays the notes out as a masonry.

States: add .is-detail to centre one raised .gv-sticky.is-raised note; the default state is the pile.

CTA: .gv-issuecanvas__add pins the floating "Add an idea" button to the bottom-right of the canvas.

Rail: in a full page the canvas sits beside .gv-issuefeed / __rail (Back link, title, participant bubbles, framing question and ranked theme cards) — see pages/fo-method-perspectives/feed/.
