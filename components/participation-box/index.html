Participation box

The resident-facing project CTA block. It aggregates the project's active participation methods into a stack of full-width buttons, then an always-bottom participant row. The same component is mirrored in the back-office Content Builder ("Participation Box" widget) and on the project page.

States

One method + extra

Three+ methods → collapsed

No active methods

Buttons: the current-phase method is the filled .gv-btn.primary; parallel / extra methods are the neutral .gv-btn.secondary-outlined — the same pair the extra-survey CTA uses, so a project page reads consistently. Three or more visible methods collapse into one "Participate" primary.

Toggles: .gv-pbox--nobtns hides the action stack; .gv-pbox--nopeople hides the participant row.
