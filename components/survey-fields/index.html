Survey fields

The GoVocal input-form / survey field widgets — every question type, themeable via --gv-*. One shared source: govocal-survey.css + govocal-survey.js. Rendered below from a field object via GVSurvey.field({type, …}). The full page-by-page runner (wizard, progress, gating) is GVSurvey.mount() — see the Input Form page.

Reuse one field type anywhere (e.g. a matrix or ranking question):

1. Copy govocal-tokens.css, govocal-ui.css, govocal-survey.css and govocal-survey.js into your prototype.
2. el.innerHTML = GVSurvey.field({ type:'matrix', label:'…', scale:[…], statements:[…] }) — or build a whole survey with GVSurvey.mount(el, FORM).

Field types: text · multiline_text · number · select · multiselect · rating · ranking · linear_scale · sentiment · multiselect_image · matrix · map · file_upload · shapefile_upload. Colours/fonts are tokens, so every field re-skins per city via ?theme=.
