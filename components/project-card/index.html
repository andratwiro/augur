Project card + rail

The participation-project card (thumb, title, meta with status icon, CTA) and the horizontal scroll rail. The whole card is clickable via a stretched title link — no nested anchors.

Boxed grid — the homepage project card (dominant treatment)

Rail — survey cards (time + CTA)

Wide cards — people count + description

Square cards — completed (done status)

No nested anchors: the card is an <article>; the .gv-pcard__title a is stretched (::after { inset:0 }) so the whole card is one click target. A secondary .gv-pcard__cta sits above it with z-index:1 so it stays separately clickable.

Meta variants: .time (clock, tenant colour), .people (count), .done (green check) — status is never colour-alone.

Widths: default 250px · .wide 360px (16:9) · .square 210px (1:1). Replace the placeholder thumb with <img> for real projects.

Boxed grid (homepage): the dominant treatment — .gv-pcard.boxed in a .gv-pgrid (white, 1px border, soft elevation, 16:9 thumb). A .gv-pcard__top meta row carries progress (.gv-pcard__topprog), a status pill (.gv-status-label / .gv-poststat) or a folder .gv-pcard__topicon, plus the outlined CTA; the .gv-pcard__foot holds the avatar stack + count. .horizontal.feature span-3 is the full-width hero card. Grid is 2-up, collapsing to 1-up below 640px.
