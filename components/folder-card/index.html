Folder card

The projects-list folder card — a white card carrying a green project-count line, the folder title, a description preview, and a stack of child-project previews that grow the card to ~583px. Source-grounded on St Louis (stlouis.govocal.com/projects).

Folder cards — the live /projects grid

System vs skin. The card geometry is the cross-tenant SYSTEM and maps to tokens: white fill, --gv-radius (3px), --gv-shadow (0 2px 4px -1px rgba(0,0,0,.06)), padding 18px 0 25px, the 16px/300 --gv-text-secondary description preview. The project-count NUMBER uses the SYSTEM positive/count green --gv-folder-count (#358545, probed on St Louis) — common across tenants, NOT per-city skin, so the ?theme= switcher (which sets only the four tenant vars) correctly leaves it unchanged. Reuses .gv-pcard.boxed wholesale.
